# ATM Management System 🏧

## 📌 Project Description
This is a simple ATM Management System developed using Python and Object-Oriented Programming (OOP). It allows users to check their balance, deposit money, and withdraw money through a menu-driven interface.

## 🚀 Features
- **Check Balance:** View the current account balance.
- **Deposit Money:** Add money to the account.
- **Withdraw Money:** Withdraw money from the account.
- **Input Validation:** Handles invalid number inputs.
- **Error Handling:** Prevents negative or zero deposits and withdrawals, and withdrawals exceeding the available balance.
- **Menu-Driven Interface:** Provides easy navigation through ATM operations.
- **Exit:** Safely exit the application.

## 🛠️ Technologies Used
- Python 3
- Object-Oriented Programming (OOP)
- Exception Handling
- Classes and Objects
